# Diccionario de Datos

| Variable         | Tipo   | Descripción                                   |
| ---------------- | ------ | --------------------------------------------- |
| legajo           | int    | Número identificador único del empleado       |
| nombre_empleado  | string | Nombre y apellido del empleado                |
| dias_solicitados | int    | Cantidad de días de vacaciones solicitados    |
| saldo            | int    | Cantidad de días de vacaciones disponibles    |
| estado           | string | Estado de la solicitud (Aprobada o Rechazada) |
| fecha_solicitud  | date   | Fecha en la que se realiza la solicitud       |
| motivo           | string | Motivo del rechazo o resultado de validación  |
